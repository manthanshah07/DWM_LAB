Data Warehousing and Mining (DWM) — Experiment 06¶

Experiment Title: Gaussian Naive Bayes Classification for Market Regime Prediction¶

Dataset: stock_market_data.csv (3 Years of Daily NSE Trading Data across 20 Major Indian Equities)

1. Objectives & Theoretical Formulation¶

  • Core Objective: Implement a Gaussian Naive Bayes (GNB) probabilistic classifier on multi-stock equity data to classify next-session return regimes (Low, Medium, High), inspect class prior probabilities $P(C_k)$ and feature conditional likelihood parameters $(\mu_{ki}, \sigma_{ki}^2)$, and evaluate out-of-sample generalization against a Majority-Class Baseline and Decision Tree using Accuracy, Weighted Precision, Weighted Recall, and Weighted F1-Score.
  • Bayes' Theorem for Continuous Features: $$P(C_k \mid \mathbf{X}) = \frac{P(C_k) \prod_{i=1}^d P(X_i \mid C_k)}{P(\mathbf{X})}$$ where continuous predictors are assumed to follow a univariate Gaussian normal distribution within each class $C_k$: $$P(X_i \mid C_k) = \frac{1}{\sqrt{2\pi\sigma_{ki}^2}} \exp\left( -\frac{(X_i - \mu_{ki})^2}{2\sigma_{ki}^2} \right)$$
  • Target Variable ($y$): Forward percentage return $\text{Next\_Day\_Return}_{t+1} = \left( \frac{\text{Close}_{t+1} - \text{Close}_t}{\text{Close}_t} \right) \times 100$ discretized into 3 empirical statistical regimes.
  • Statistical Empirical Return Regimes (Training Set Distribution Tertiles): Regime boundaries are calibrated strictly on the training set 33.3% and 66.7% quantiles:
    • Low (Bottom Tertile): $\text{Next\_Day\_Return} < q_1$ (approximately $\le -0.431\%$)
    • Medium (Middle Tertile): $q_1 \le \text{Next\_Day\_Return} < q_2$ (approximately $-0.431\%$ to $+0.495\%$)
    • High (Upper Tertile): $\text{Next\_Day\_Return} \ge q_2$ (approximately $\ge +0.495\%$)

    Methodological Note: These classes represent purely statistical empirical regimes partitioning the historical training return distribution for balanced multi-class learning. These boundaries are statistical partitions of the historical sample distribution and are not calibrated trading signals.

  • Predictive Feature Space ($X$): Exclusively lagged technical features available at session $t$ prior to next session open:
    1. Lag1_Return: Prior close-to-close return.
    2. Lag1_Volatility: Prior intraday spread range ($\frac{\text{High}_t - \text{Low}_t}{\text{Open}_t} \times 100$).
    3. Lag1_Volume_Log: Log-transformed prior volume ($\ln(1 + \text{Volume}_t)$).
    4. Month: Calendar month (1–12).
  • Unified Evaluation Protocol & Boundary Purging:
    • Common supervised population across all experiments (14,680 observations, 734 unique trading dates).
    • Datetime-based chronological 80:20 split (587 dates, 11,740 observations train; 146 dates, 2,920 observations test).
    • 1-session boundary purge on 2026-03-06 strictly separates training target realizations from test feature inputs: $\max(\text{Train Target Date}) < \min(\text{Test Feature Date})$.

3. Data Ingestion, Datetime Handling & Purged Temporal Split¶

Ingest stock_market_data.csv, compute per-ticker chronological lags and forward returns, apply the common evaluation eligibility filter, perform a purged chronological 80:20 split, and derive training-calibrated empirical tertiles.

# 1. Ingest dataset and parse dates
df = pd.read_csv('stock_market_data.csv')
df['Date_dt'] = pd.to_datetime(df['Date'])

# 2. Sort chronologically per ticker using parsed datetime objects
df_sorted = df.sort_values(['Ticker', 'Date_dt']).reset_index(drop=True)
records = []

for ticker, grp in df_sorted.groupby('Ticker'):
    g = grp.copy().sort_values('Date_dt').reset_index(drop=True)
    g['Next_Day_Return'] = ((g['Close_Price'].shift(-1) - g['Close_Price']) / g['Close_Price']) * 100
    g['Target_Date'] = g['Date_dt'].shift(-1)
    g['Lag1_Return'] = ((g['Close_Price'] - g['Close_Price'].shift(1)) / g['Close_Price'].shift(1)) * 100
    g['Lag1_Intraday'] = ((g['Close_Price'] - g['Open_Price']) / g['Open_Price']) * 100
    g['Lag1_Volatility'] = ((g['High_Price'] - g['Low_Price']) / g['Open_Price']) * 100
    g['Lag1_Volume_Log'] = np.log1p(g['Volume'])
    g['SMA5_Return'] = g['Lag1_Return'].rolling(window=5).mean()
    g['Month'] = g['Date_dt'].dt.month
    records.append(g)

feat_df = pd.concat(records, ignore_index=True)
feature_cols = ['Lag1_Return', 'Lag1_Volatility', 'Lag1_Volume_Log', 'Month']
common_req_cols = ['Next_Day_Return', 'Target_Date', 'Lag1_Return', 'Lag1_Intraday', 'Lag1_Volatility', 'Lag1_Volume_Log', 'SMA5_Return', 'Month']

# Common evaluation population eligibility filter
clean_df = feat_df.dropna(subset=common_req_cols).reset_index(drop=True)

# 3. Datetime-based Chronological 80:20 Train-Test split with 1-session boundary purge
unique_dates = sorted(clean_df['Date_dt'].unique())
split_idx = int(len(unique_dates) * 0.8)
train_dates = set(unique_dates[:split_idx])

train_df = clean_df[clean_df['Date_dt'].isin(train_dates)].reset_index(drop=True)
max_train_target_date = train_df['Target_Date'].max()

# Purge: test set starts strictly after max train target date
test_df = clean_df[clean_df['Date_dt'] > max_train_target_date].reset_index(drop=True)

# 4. Calibrate empirical statistical tertiles strictly on training set
q1 = float(train_df['Next_Day_Return'].quantile(1 / 3))
q2 = float(train_df['Next_Day_Return'].quantile(2 / 3))

def assign_regime(val):
    if val < q1:
        return 'Low'
    elif val < q2:
        return 'Medium'
    else:
        return 'High'

train_df['Return_Category'] = train_df['Next_Day_Return'].apply(assign_regime)
test_df['Return_Category'] = test_df['Next_Day_Return'].apply(assign_regime)

print("=== Chronological Split & Boundary Purging Audit ===")
print(f"Total Supervised Observations: {len(clean_df):,} ({clean_df['Date_dt'].nunique()} dates x 20 stocks)")
print(f"Training Feature Dates:       {train_df['Date_dt'].min().strftime('%Y-%m-%d')} to {train_df['Date_dt'].max().strftime('%Y-%m-%d')} ({train_df['Date_dt'].nunique()} dates, {len(train_df):,} rows)")
print(f"Training Target Dates:        {train_df['Target_Date'].min().strftime('%Y-%m-%d')} to {max_train_target_date.strftime('%Y-%m-%d')}")
print(f"Purged Boundary Date:         {pd.to_datetime(unique_dates[split_idx]).strftime('%Y-%m-%d')} (1 session isolated to eliminate label-to-feature overlap)")
print(f"Testing Feature Dates:        {test_df['Date_dt'].min().strftime('%Y-%m-%d')} to {test_df['Date_dt'].max().strftime('%Y-%m-%d')} ({test_df['Date_dt'].nunique()} dates, {len(test_df):,} rows)")
print(f"Testing Target Dates:         {test_df['Target_Date'].min().strftime('%Y-%m-%d')} to {test_df['Target_Date'].max().strftime('%Y-%m-%d')}")
print(f"Temporal Non-Overlap Check:   max(Train Target) < min(Test Feature) -> {max_train_target_date < test_df['Date_dt'].min()}")

9. Academic Findings & Performance Nuance¶

  1. Model Evaluation & Metric Nuance (Accuracy vs. F1):
    • Empirical Majority Class: In the training partition (11,740 observations), the majority class is dynamically identified as High (3,914 instances, 33.34%).
    • Out-of-Sample Accuracy: On the 2,920 purged test sessions, the Majority Baseline achieves 33.01%, Gaussian Naive Bayes achieves 31.88%, and the Decision Tree achieves 36.37%. The Decision Tree outperforms both the baseline and random guessing (33.33%), whereas GNB falls slightly below the baseline.
    • Weighted F1-Score: The Majority Baseline yields an F1-score of only 0.1639 due to complete blindness to Low and Medium regimes. Both Gaussian Naive Bayes (0.2843) and the Decision Tree (0.3585) achieve substantially higher F1-scores by actively predicting across all three empirical regimes.
  2. Conditional Independence & Covariance Violation:
    • Gaussian Naive Bayes assumes that features are conditionally independent given the class: $P(X_i, X_j \mid C_k) = P(X_i \mid C_k) P(X_j \mid C_k)$.
    • In equity markets, trading volume and intraday spread volatility exhibit strong empirical covariance. Under extreme volume conditions, spread volatility also expands, directly violating the independence assumption and causing calibrated posterior probabilities to become overly concentrated.
  3. Critical Quantitative & Trading Profitability Nuance:
    • Although the Decision Tree's 36.37% accuracy marginally surpasses the uninformative baseline (33.01%), this does NOT imply a viable trading strategy or economic profitability.
    • Statistical accuracy on empirical return tertiles does not account for real-world trading frictions, including brokerage commissions, transaction taxes, exchange levies, bid-ask spread crossing costs, execution slippage, and asymmetric tail risks.
  4. Methodological Validity:
    • Enforcing strict chronological datetime sorting, separate per-ticker lag calculations, explicit target dates, common eligibility filtering, and a 1-session boundary purge ensures that all reported metrics represent genuine out-of-sample generalization without lookahead bias.
