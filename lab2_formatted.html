Experiment 02: OLAP Operations on the Dimensional Model

1. Aim / Objective

To perform standard OLAP (Online Analytical Processing) operations — Slice, Dice, Roll-Up, Drill-Down, Pivot, and Drill-Across — on the Stock Market Data Warehouse built in Experiment 01, using SQL queries executed against a SQLite in-memory warehouse populated from stock_market_data.csv.

2. Theory

2.1 OLAP Concepts

OLAP enables multidimensional analysis of business data. Operations traverse the data cube defined by the warehouse dimensions (Time, Stock, Exchange).

OperationDescription
SliceSelects a single value of one dimension, producing a sub-cube.
DiceApplies range/value filters on two or more dimensions.
Roll-UpAggregates data up a hierarchy (Month → Quarter → Year).
Drill-DownDecomposes aggregated data to a finer granularity.
PivotRotates the data cube to present a cross-tabulated view.
Drill-AcrossQueries across multiple fact tables sharing conformed dimensions.

3. OLAP Query Results

3.1 Slice Operation

Extracts a single dimension value — all trades for the NSE exchange.

SELECT t.Year, s.Ticker, s.Sector,
       ROUND(AVG(f.Close_Price), 2)   AS Avg_Close,
       ROUND(AVG(f.Daily_Return), 4)  AS Avg_Return,
       SUM(f.Volume)                  AS Total_Volume
  FROM Fact_DailyTrades f
  JOIN Dim_Time     t ON f.Time_Key     = t.Time_Key
  JOIN Dim_Stock    s ON f.Stock_Key    = s.Stock_Key
  JOIN Dim_Exchange e ON f.Exchange_Key = e.Exchange_Key
 WHERE e.Exchange = 'NSE'
 GROUP BY t.Year, s.Ticker, s.Sector
 ORDER BY t.Year, s.Ticker
 LIMIT 10;

3.2 Dice Operation

Applies filters on two+ dimensions — IT sector stocks in 2023 with positive returns.

SELECT t.Year, t.Quarter, s.Ticker, s.Sector,
       ROUND(AVG(f.Close_Price), 2)   AS Avg_Close,
       ROUND(AVG(f.Daily_Return), 4)  AS Avg_Return,
       SUM(f.Volume)                  AS Total_Volume
  FROM Fact_DailyTrades f
  JOIN Dim_Time  t ON f.Time_Key  = t.Time_Key
  JOIN Dim_Stock s ON f.Stock_Key = s.Stock_Key
 WHERE s.Sector = 'IT'
   AND t.Year   = 2023
   AND f.Daily_Return > 0
 GROUP BY t.Year, t.Quarter, s.Ticker
 ORDER BY t.Quarter, Avg_Return DESC
 LIMIT 10;

3.3 Roll-Up Operation

Aggregates from Month → Quarter → Year hierarchy.

SELECT t.Year, t.Quarter,
       ROUND(AVG(f.Close_Price),  2)  AS Avg_Close,
       ROUND(AVG(f.Daily_Return), 4)  AS Avg_Daily_Return,
       SUM(f.Volume)                  AS Total_Volume,
       COUNT(*)                       AS Trade_Days
  FROM Fact_DailyTrades f
  JOIN Dim_Time t ON f.Time_Key = t.Time_Key
 GROUP BY t.Year, t.Quarter
 ORDER BY t.Year, t.Quarter
 LIMIT 12;

3.4 Drill-Down Operation

Decomposes from Year → Quarter → Month for INFY.

SELECT t.Year, t.Quarter, t.Month,
       ROUND(AVG(f.Close_Price),  2) AS Avg_Close,

       SUM(f.Volume)                 AS Total_Volume
  FROM Fact_DailyTrades f

3.5 Pivot Operation

Cross-tabulates average daily return per sector per year.

SELECT s.Sector,
       ROUND(AVG(CASE WHEN t.Year = 2021 THEN f.Daily_Return END), 4) AS [2021],
       ROUND(AVG(CASE WHEN t.Year = 2022 THEN f.Daily_Return END), 4) AS [2022],
       ROUND(AVG(CASE WHEN t.Year = 2023 THEN f.Daily_Return END), 4) AS [2023],
       ROUND(AVG(CASE WHEN t.Year = 2024 THEN f.Daily_Return END), 4) AS [2024]
  FROM Fact_DailyTrades f
  JOIN Dim_Stock s ON f.Stock_Key = s.Stock_Key
  JOIN Dim_Time  t ON f.Time_Key  = t.Time_Key
 GROUP BY s.Sector
 ORDER BY s.Sector;

3.6 Drill-Across Operation

Joins two fact tables (DailyTrades + QuarterlyFinancials) via conformed dims.

SELECT s.Ticker, s.Sector, t.Year, t.Quarter,
       ROUND(AVG(f.Daily_Return), 4) AS Avg_Daily_Return,
       ROUND(AVG(f.Volume),       0) AS Avg_Volume,
       ROUND(AVG(q.EPS),          2) AS Avg_EPS,
       ROUND(AVG(q.PE_Ratio),     2) AS Avg_PE
  FROM Fact_DailyTrades f
  JOIN Dim_Stock s ON f.Stock_Key = s.Stock_Key
  JOIN Dim_Time  t ON f.Time_Key  = t.Time_Key
  JOIN Fact_QuarterlyFinancials q
       ON q.Stock_Key = f.Stock_Key AND q.Time_Key = f.Time_Key
 GROUP BY s.Ticker, t.Year, t.Quarter
 ORDER BY s.Ticker, t.Year, t.Quarter
 LIMIT 10;

Conclusion: All six OLAP operations were successfully executed on the Stock Market Data Warehouse. Slice isolated NSE-listed stocks; Dice filtered IT-sector positive-return days in 2023; Roll-Up aggregated trade metrics to the quarterly level; Drill-Down decomposed INFY's performance month-by-month; Pivot cross-tabulated sector-wise average returns by year; and Drill-Across joined daily trade facts with quarterly financials via conformed dimensions, demonstrating the power of a multi-fact constellation schema.
